# House Price Regression

Учебный проект по построению и сравнению моделей регрессии для прогнозирования стоимости недвижимости.

## Что реализовано

* загрузка и анализ набора данных о недвижимости;
* визуализация взаимосвязей между площадью, количеством комнат и стоимостью;
* линейная регрессия по площади дома;
* полиномиальная регрессия второй и третьей степени;
* линейная регрессия по площади дома и количеству комнат;
* оценка моделей с использованием MSE, RMSE и MAE;
* прогноз стоимости для заданных объектов недвижимости.

Для прогнозирования используются два объекта:

* площадь `1650.3`, количество комнат `3`;
* площадь `2200.4`, количество комнат `4`.

## Визуализация

В проекте строятся четыре графика:

1. зависимость стоимости от площади;
2. зависимость стоимости от количества комнат;
3. зависимость площади от количества комнат;
4. сравнение полиномиальных моделей второй и третьей степени.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить программу:

```bash
python main.py
```

Программа загружает данные, строит графики, обучает модели регрессии, рассчитывает метрики качества и выводит прогнозируемую стоимость недвижимости.
